# Sentiment Analysis

<Endpoint method="GET" path="/v1/analytics/sentiment" />

Returns sentiment data as a time-series with an overall summary. Each data point breaks down signal counts by sentiment class (positive, negative, neutral, mixed) and includes the average sentiment score for that interval. The `overall` object provides the aggregate totals across the entire window.

Use this endpoint to track how sentiment evolves over time, detect sudden shifts toward negative or positive coverage, and filter by category for targeted sentiment monitoring.

## Parameters

<ParamTable params={[
  { name: "hours", type: "integer", required: false, default: "24", description: "Lookback window in hours. Min 1, max 72." },
  { name: "interval", type: "string", required: false, default: "hour", description: "Grouping interval. One of `hour` or `day`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/analytics/sentiment" params="hours=24" />

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `interval` | string | The interval used for grouping (`hour` or `day`). |
| `dataPoints` | array | Time-series data. Each point has `timestamp`, `positive`, `negative`, `neutral`, `mixed`, and `avgScore`. |
| `overall` | object | Aggregate totals: `positive`, `negative`, `neutral`, `mixed`, and `avgScore` across the full window. |
