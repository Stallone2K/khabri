# Category Distribution

<Endpoint method="GET" path="/v1/analytics/categories" />

Returns the distribution of signals across categories for a given time window. Each category includes its signal count and percentage of the total. The response also reports the total number of categorized signals and the count of uncategorized signals.

Use this endpoint to understand which topics are dominating signal intake and how the category mix shifts over different time windows.

## Parameters

<ParamTable params={[
  { name: "hours", type: "integer", required: false, default: "24", description: "Lookback window in hours (1-72)" },
]} />

## Request Example

<RequestExample method="GET" path="/v1/analytics/categories" params="hours=24" />
