# Analytics

The Analytics API provides aggregate views of signal data across configurable time windows. Use these endpoints to build dashboards, monitor trends in signal volume, understand category distributions, and track sentiment shifts over time.

## Core Concepts

### Time Windows

All analytics endpoints accept an `hours` parameter (1-72, default 24) that defines the lookback window. Data is computed in real time from the signals collected during that period.

### Intervals

The volume and sentiment endpoints support `interval` grouping -- either `hour` or `day`. Hourly intervals are the default and provide more granular time-series data. Daily intervals are useful for longer time windows (48-72 hours).

### Categories and Sentiment

Khabri enriches every signal with a category and sentiment classification. The analytics endpoints aggregate these classifications so you can see macro-level patterns without querying individual signals.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
