# Signal Volume

<Endpoint method="GET" path="/v1/analytics/volume" />

Returns signal volume as a time-series, grouped by the specified interval. Each data point contains a timestamp and the count of signals ingested during that interval. The response also includes the total signal count for the entire window.

Use this endpoint to visualize signal ingestion rates, detect quiet or busy periods, and identify sudden spikes in activity.

## Parameters

<ParamTable params={[
  { name: "hours", type: "integer", required: false, default: "24", description: "Lookback window in hours. Min 1, max 72." },
  { name: "interval", type: "string", required: false, default: "hour", description: "Grouping interval. One of `hour` or `day`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/analytics/volume" params="hours=24" />

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `interval` | string | The interval used for grouping (`hour` or `day`). |
| `dataPoints` | array | Array of time-series data points, each with `timestamp` and `count`. |
| `total` | integer | Total signal count across the entire window. |
