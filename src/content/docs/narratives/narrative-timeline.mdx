# Narrative Timeline

<Endpoint method="GET" path="/v1/narratives/{id}/timeline" />

Returns the timeline data for a narrative, including the current arc phase and chronological data points. Each data point represents signal activity at a given timestamp, allowing you to visualize how the narrative has evolved over time.

Use this endpoint to chart the intensity of a narrative and identify when it transitioned between arc phases (emergence, escalation, peak, resolution).

## Parameters

<ParamTable params={[
  { name: "id", type: "string", required: true, default: "-", description: "The narrative node ID. Path parameter." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/narratives/nar_8f3k2m1/timeline" />
