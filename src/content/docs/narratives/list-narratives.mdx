# List Narratives

<Endpoint method="GET" path="/v1/narratives" />

Returns a paginated list of root-level narrative nodes across all projects. Each narrative includes its title, summary, keywords, signal count, arc phase, and child/event/stakeholder counts.

## Parameters

<ParamTable params={[
  { name: "page", type: "integer", required: false, default: "1", description: "Page number (1-based)." },
  { name: "page_size", type: "integer", required: false, default: "25", description: "Items per page. Also accepts `limit`. Min 1, max 100." },
  { name: "status", type: "string", required: false, default: "-", description: "Filter narratives by status." },
  { name: "arc_phase", type: "string", required: false, default: "-", description: "Filter by arc phase. One of `EMERGENCE`, `ESCALATION`, `PEAK`, `RESOLUTION`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/narratives" params="page=1&page_size=5" />
