# Narrative Stakeholders

<Endpoint method="GET" path="/v1/narratives/{id}/stakeholders" />

Returns the stakeholders associated with a narrative and its entire subtree. Stakeholders are the key actors -- people, organizations, companies, and countries -- that appear across the signals linked to the narrative. Each stakeholder includes a role classification, sentiment score, and mention count.

## Parameters

<ParamTable params={[
  { name: "id", type: "string", required: true, default: "-", description: "The narrative node ID. Path parameter." },
  { name: "type", type: "string", required: false, default: "-", description: "Filter by stakeholder type. One of `PERSON`, `ORG`, `COMPANY`, `COUNTRY`." },
  { name: "sort", type: "string", required: false, default: "mentions", description: "Sort order. One of `mentions`, `sentiment`, `name`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/narratives/nar_8f3k2m1/stakeholders" params="sort=mentions" />

## Response Fields

Each stakeholder object contains:

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | The name of the stakeholder. |
| `type` | string | Entity type: `PERSON`, `ORG`, `COMPANY`, or `COUNTRY`. |
| `role` | string or null | Role in the narrative: `PROTAGONIST`, `ANTAGONIST`, `REGULATOR`, or `OBSERVER`. |
| `sentiment` | number or null | Average sentiment score from -1 (negative) to 1 (positive). |
| `mentionCount` | integer | Total number of signal mentions across the narrative subtree. |
| `lastSeenAt` | string or null | ISO 8601 timestamp of the most recent mention. |
