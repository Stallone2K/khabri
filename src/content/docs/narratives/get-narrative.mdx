# Get Narrative

<Endpoint method="GET" path="/v1/narratives/{id}" />

Returns the complete narrative tree for a given root or sub-narrative. The response includes the full hierarchy of child nodes, associated events, and stakeholders. This is the primary endpoint for understanding the structure of an evolving story.

## Parameters

<ParamTable params={[
  { name: "id", type: "string", required: true, default: "-", description: "The narrative node ID. Path parameter." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/narratives/nar_8f3k2m1" />
