# Khabri Intelligence API

The Khabri API gives you programmatic access to our intelligence platform. Track trends, monitor signals, detect anomalies, follow narratives, and analyze geographic patterns — all through a simple REST API.

## Base URL

```
https://khabri.stallone.co.in/api/v1
```

All endpoints are prefixed with `/api/v1`. Authentication is required for every request via a Bearer token in the `Authorization` header.

## Quick Start

**1. Get your API key** from the [Developer Portal](/dashboard/developer).

**2. Make your first request:**

## What You Can Build

- **News aggregators** — Use Trends and Signals to surface breaking stories
- **Risk dashboards** — Monitor Anomalies for sudden spikes in activity
- **Research tools** — Track Narratives to follow evolving stories over time
- **Geographic monitoring** — Use Geo endpoints for location-based intelligence
- **Alert systems** — Subscribe to Webhooks or SSE streams for real-time notifications
- **Analytics platforms** — Integrate volume, sentiment, and category data into your dashboards

## Response Format

All successful responses follow a consistent structure:

```json
{
  "data": "...",
  "meta": {
    "total": 100,
    "page": 1,
    "pageSize": 25,
    "hasMore": true
  }
}
```

- `data` — The requested resource(s). Can be an object or an array.
- `meta` — Pagination info (for list endpoints) and rate limit details.
