# List Anomalies

<Endpoint method="GET" path="/v1/anomalies" />

Returns a paginated list of detected anomaly events along with a severity summary. Each anomaly includes statistical details (z-score, current value, baseline mean and standard deviation) so you can assess the magnitude of each deviation. By default, only active (unresolved) anomalies are returned.

## Parameters

<ParamTable params={[
  { name: "page", type: "integer", required: false, default: "1", description: "Page number (1-based)." },
  { name: "page_size", type: "integer", required: false, default: "25", description: "Items per page. Min 1, max 100." },
  { name: "type", type: "string", required: false, default: "-", description: "Filter by anomaly type. One of `KEYWORD_SPIKE`, `ENTITY_SURGE`, `SENTIMENT_SHIFT`, or `GEO_CONCENTRATION`." },
  { name: "severity", type: "string", required: false, default: "-", description: "Filter by severity. One of `ELEVATED`, `HIGH`, or `CRITICAL`." },
  { name: "active", type: "string", required: false, default: "true", description: "Filter by resolved status. `true` for active only, `false` for all." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/anomalies" params="severity=CRITICAL" />
