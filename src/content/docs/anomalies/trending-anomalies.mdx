# Trending Anomalies

<Endpoint method="GET" path="/v1/anomalies/trending" />

Returns the most significant trending anomalies, ranked by z-score. Each result includes a `sparkline` array of 24 hourly data points representing the metric's value over the past 24 hours, suitable for rendering inline charts. You can filter by dimension type to focus on keyword or entity anomalies.

## Parameters

<ParamTable params={[
  { name: "limit", type: "integer", required: false, default: "10", description: "Number of trending anomalies to return. Min 1, max 20." },
  { name: "type", type: "string", required: false, default: "-", description: "Filter by dimension type. One of `keyword` or `entity`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/anomalies/trending" params="limit=5" />
