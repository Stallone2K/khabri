# Country Intelligence

<Endpoint method="GET" path="/v1/geo/{countryCode}" />

Returns a comprehensive intelligence summary for a specific country, including recent signals, category breakdown, sentiment distribution, and an AI-generated briefing. This endpoint gives you a complete picture of the intelligence landscape for any country Khabri is tracking.

## Parameters

<ParamTable params={[
  { name: "countryCode", type: "string", required: true, default: "-", description: "ISO 3166-1 alpha-2 country code (e.g., `US`, `IN`, `DE`). Path parameter." },
  { name: "hours", type: "integer", required: false, default: "24", description: "Time window in hours. Min 1, max 72." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/geo/IN" params="hours=24" />

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `country` | object | Country info with `code` and `name`. |
| `signalCount` | integer | Total signals for this country in the time window. |
| `signals` | array | Recent signals associated with this country. |
| `categories` | object | Signal counts broken down by category. |
| `sentimentBreakdown` | object | Signal counts broken down by sentiment. |
| `briefing` | string or null | AI-generated intelligence summary for this country. |
