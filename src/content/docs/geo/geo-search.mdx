# Geo Search

<Endpoint method="GET" path="/v1/geo/search" />

Search for signals associated with a specific geographic location. The API resolves the location name, determines its scope within the location hierarchy (city, state, country, region), and returns matching signals along with an AI-generated briefing summarizing activity at that location.

## Parameters

<ParamTable params={[
  { name: "location", type: "string", required: true, default: "-", description: "Location name or alias to search for (e.g., `Mumbai`, `United States`, `EU`)." },
  { name: "radius", type: "string", required: false, default: "-", description: "Resolution level to expand the search to. One of `CITY`, `STATE`, `COUNTRY`, `REGION`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/geo/search" params="location=Mumbai" />

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `location` | object | The resolved location with `id`, `name`, `type`, and `countryCode`. |
| `scope` | object | The scope used for the search with `id`, `name`, and `type`. |
| `ancestors` | array | Parent locations in the hierarchy (e.g., city -> state -> country). |
| `signals` | array | Matching signals at this location. |
| `signalCount` | integer | Total number of matching signals. |
| `briefing` | string or null | AI-generated summary of the situation at this location. |
