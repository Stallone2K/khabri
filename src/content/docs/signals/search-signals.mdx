# Search Signals

<Endpoint method="GET" path="/v1/signals/search" />

Search across the signals database using text queries, entity names, locations, or country codes. At least one of `q`, `entity`, `location`, or `country` is required. Results are paginated and include full enrichment data.

## Parameters

<ParamTable params={[
  { name: "q", type: "string", required: false, default: "-", description: "Full-text search on signal titles." },
  { name: "entity", type: "string", required: false, default: "-", description: "Entity name to search for (partial match)." },
  { name: "entity_type", type: "string", required: false, default: "-", description: "Entity type filter. One of `PERSON`, `ORG`, `COMPANY`, `COUNTRY`, or `LOCATION`. Requires the `entity` parameter." },
  { name: "location", type: "string", required: false, default: "-", description: "Location name to search for (partial match)." },
  { name: "country", type: "string", required: false, default: "-", description: "ISO 3166-1 alpha-2 country code (e.g., `US`, `IN`)." },
  { name: "page", type: "integer", required: false, default: "1", description: "Page number (1-based)." },
  { name: "page_size", type: "integer", required: false, default: "25", description: "Items per page. Min 1, max 100." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/signals/search" params="q=tariff" />
