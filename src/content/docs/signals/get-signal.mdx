# Get Signal

<Endpoint method="GET" path="/v1/signals/{id}" />

Returns the complete details for a single signal, including all enrichment data. The response includes the `enrichedAt` timestamp indicating when enrichment processing was completed.

## Parameters

<ParamTable params={[
  { name: "id", type: "string", required: true, default: "-", description: "The unique signal identifier (e.g., `sig_x1y2z3w4`). Passed as a path parameter." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/signals/sig_x1y2z3w4" />
