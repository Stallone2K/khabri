# List Signals

<Endpoint method="GET" path="/v1/signals" />

Returns a paginated list of signals, each including its enrichment data (entities, keywords, locations, and sentiment). Use the query parameters to filter by category, sentiment, source, time window, or enrichment status.

## Parameters

<ParamTable params={[
  { name: "page", type: "integer", required: false, default: "1", description: "Page number (1-based)." },
  { name: "page_size", type: "integer", required: false, default: "25", description: "Items per page. Min 1, max 100. Also accepts `limit`." },
  { name: "category", type: "string", required: false, default: "-", description: "Filter by category (e.g., `Politics`, `Technology`)." },
  { name: "sentiment", type: "string", required: false, default: "-", description: "Filter by sentiment. One of `POSITIVE`, `NEGATIVE`, `NEUTRAL`, or `MIXED`." },
  { name: "source", type: "string", required: false, default: "-", description: "Filter by source name (partial match)." },
  { name: "since", type: "string (ISO 8601)", required: false, default: "-", description: "Only return signals published after this date-time." },
  { name: "enriched", type: "string", required: false, default: "-", description: "Filter by enrichment status. `true` or `false`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/signals" params="page=1&page_size=5" />
