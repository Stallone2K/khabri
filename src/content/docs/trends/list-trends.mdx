# List Trends

<Endpoint method="GET" path="/v1/trends" />

Returns a paginated list of trends ranked by Khabri's scoring algorithm. Trends are ordered by rank by default, but you can sort by score or creation date instead. Use the filtering parameters to narrow results by category, region, or minimum score threshold.

## Parameters

<ParamTable params={[
  { name: "page", type: "integer", required: false, default: "1", description: "Page number (1-based)." },
  { name: "page_size", type: "integer", required: false, default: "25", description: "Items per page. Min 1, max 100. Also accepts `limit`." },
  { name: "category", type: "string", required: false, default: "-", description: "Filter by category (e.g., `Politics`, `Technology`)." },
  { name: "region", type: "string", required: false, default: "-", description: "Filter by region. One of `DOMESTIC` or `INTERNATIONAL`." },
  { name: "min_score", type: "integer", required: false, default: "-", description: "Only return trends with a score at or above this threshold." },
  { name: "sort", type: "string", required: false, default: "rank", description: "Sort order. One of `rank`, `score`, or `created_at`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/trends" params="page=1&page_size=5" />
