# Top Trends

<Endpoint method="GET" path="/v1/trends/top" />

Returns the highest-ranked trending topics along with momentum data. Each trend includes a directional `change` indicator (up, down, or neutral) and the current signal `volume`, making it easy to spot accelerating stories at a glance.

## Parameters

<ParamTable params={[
  { name: "limit", type: "integer", required: false, default: "10", description: "Number of top trends to return. Min 1, max 30." },
  { name: "region", type: "string", required: false, default: "-", description: "Filter by region. One of `DOMESTIC` or `INTERNATIONAL`." },
]} />

## Request Example

<RequestExample method="GET" path="/v1/trends/top" params="limit=5" />
